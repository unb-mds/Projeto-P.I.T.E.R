## Papeis e Responsabilidades

### Desenvolvimento Frontend
- Implementacao da interface com Next.js e React
- Estilizacao com TailwindCSS
- Criacao de graficos com Recharts
- Integracao com o backend

### Desenvolvimento Backend
- API FastAPI em Python
- Integracao com Querido Diario API
- Processamento de dados e extracao de valores
- Integracao com Google Gemini

### DevOps e Infraestrutura
- Configuracao do Docker
- Pipeline de CI/CD
- Deploy e hospedagem
- Documentacao tecnica

### Gestao e Documentacao
- Organizacao das sprints
- Documentacao do projeto
- Comunicacao da equipe
- Controle de qualidade
